# Posi_MA_Lab-demo-site

Demo target repository for [Posi_MA_Lab](https://github.com/martin3513/Posi_MA_Lab).
A coding agent (OpenCode in a Docker sandbox) pushes to `agent/*` branches here after a human approves the push.
A human merges to `main` through a pull request.

Contents are public demo material only (a competitor-analysis comparison page). No secrets, no customer data.
